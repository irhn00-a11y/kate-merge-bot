# ケイトの冒険 自動マージbot

## 準備（PC側・初回のみ）
1. Android SDK Platform-Tools（adb）を入れて PATH を通す
2. スマホ：設定 → 端末情報 → ビルド番号を7回タップ → 開発者オプション →「USBデバッグ」ON
   - **「USBデバッグ（セキュリティ設定）」もON**（Xiaomi/POCO系はこれが無いとタップ入力が拒否される）
3. USB接続して `adb devices` で `device` と出ればOK（ワイヤレスデバッグでも可）
4. `pip install opencv-python numpy`
5. 見る用：`scrcpy` でミラーリング（botの動作とは独立）

## 使い方
```
python kate_merge_bot.py --analyze shot.jpg   # スクショ1枚で認識テスト（ADB不要）
python kate_merge_bot.py --dry-run            # 実機を読むだけ、矢印表示のみ
python kate_merge_bot.py                      # 自動マージ開始（Ctrl+C停止）
python kate_merge_bot.py --produce 5 3        # ペア切れでオーブン(列5,行3)をタップして補充
```
マス座標は左上が (0,0)、列→右、行→下。

## 仕組み
screencap → 7x9に切る → 空き/段ボール/瓶/アイテムに分類 → 色ヒスト＋シルエットで同種判定 → 1手スワイプ → 毎回読み直し

- **実機でのADB操作は未検証**

## 調整ポイント（kate_merge_bot.py 冒頭）
- `BOARD`：盤面の位置がズレる場合
- `SAME_THRESHOLD`：違う物をくっつける→上げる／同じ物を見逃す→下げる
- `SWIPE_MS` / `WAIT_AFTER_MERGE`：速度。上げるほど「見て楽しい」寄り

## 既知の弱点
- レベル違いの同種（バター1とバター2など）を同一視する可能性。見た目が大きく違えば問題なし
- 瓶の中身への合体（解放）、ポップアップ、エネルギー切れは未対応
- 使うときは規約上の自己責任で（オンラインランキング系は特に）

## スマホ単体で動かす（Termux版）
1. Termux は **F-Droid か GitHub版** を入れる（Play版は古い）
2. このチャットから kate_merge_bot.py と termux_setup.sh をダウンロード（「ダウンロード」フォルダに入る）
3. Termuxで:
   ```
   termux-setup-storage
   cp ~/storage/downloads/kate_merge_bot.py ~/storage/downloads/termux_setup.sh ~
   bash termux_setup.sh
   ```
4. 画面の案内どおり自分自身にペアリング → `adb devices` で確認
5. `termux-wake-lock` → `python kate_merge_bot.py` → 5秒以内にゲームへ切替

### Termux版の挙動
- 画面表示窓は出ない。代わりに毎手の認識結果を `Pictures/kate_bot_latest.png` に保存（ギャラリーで確認）
- ゲーム盤面が見えない時（Termuxに戻った・ポップアップで暗転）はスワイプせず待機。約30秒戻らなければ自動停止
- 停止：Termuxに戻って Ctrl+C（戻った時点で自動的に一時停止状態になる）

### 検証状況（Termux版）
- スクショでの盤面検知テスト：通常=見える／暗転=見えない／真っ黒=見えない、で期待どおり
- Termux上での実行・自己ADB接続は**未検証**（パッケージ名は Termux公式メンバーの案内と解説記事に基づく）

## 注文保護モード（デフォルトON）
- キャラ下のクリーム色パネルから注文アイコンを毎回読み取り、盤面で同じ物は **ORDER（黄枠）として触らない**
- 判定：注文アイコンを拡大したマスク付きテンプレートマッチ。一致度 ≥ `ORDER_THRESHOLD`(0.60) かつ その注文の最高一致から `ORDER_MARGIN`(0.12) 以内
- `--ignore-orders` で無効化、`--max-merges N` でN回マージしたら停止
- 検証：実スクショ（注文=サンドイッチ・ケーキポップ、盤面に無し）→ 保護0件で正解。
  盤面アイテムを注文欄に合成したテスト7種（バター/小麦粉/スコップ/トースト/オーブン/計量カップ/生地）→ 全て該当アイテムを保護。
  小麦粉テストのみ計量カップも巻き添え保護（安全側の誤り）
- 未検証：実際の注文アイコンが盤面と同じ絵柄か、注文が複数キャラ並ぶ時の読み取り
- 未対応：注文品を作るための「レシピ逆算」、納品タップ
